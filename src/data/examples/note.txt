Example 1
--------

    - dhcp4-example-1.conf
      version 5.x example 1 - can be run and new yaml config will be generated

      Run it:
        kea-config -c dhcp4-example-1.conf

    - dhcp4-example-1.yaml
      Automatically generated YAML file created from dhcp4-example.conf.

    - Example-1
      The output files.
